# Change Proposal: pivot-to-sport-lifestyle-engine

## Summary
Pivot XIONID from a generic consumer rewards passport into a Sport Lifestyle Engine for sport lifestyle users.

XIONID must help users turn repeated lifestyle behavior into verified reputation, ranking, opportunities, and eventually income or career paths. The pilot audience is users who identify with active sport lifestyles such as running, gym/strength, cycling, swimming, hybrid athlete training, marathon/events, recovery, wellness, sports gear, and supplements.

## Product Correction
XIONID must not become:
- an EarnOS clone,
- a loyalty app,
- a voucher marketplace,
- a generic rewards app,
- or a points-only engagement mechanic.

XIONID must become a Sport Lifestyle Engine where badges, ranks, challenges, and opportunities are grounded in repeated, user-submitted or verified lifestyle behavior.

## Core Thesis
Repeated sport lifestyle behavior should become portable reputation.

XIONID should let a user:
1. express a sport lifestyle identity,
2. submit or simulate proof of that lifestyle,
3. earn tiered sport lifestyle badges,
4. create personal challenges with deadlines/countdowns,
5. build rank through repeated proofs, completed challenges, and referrals,
6. discover relevant opportunities matched to their lifestyle profile,
7. eventually convert lifestyle reputation into income, ambassador opportunities, sponsorships, coaching, events, or career pathways.

## Primary User Flow
1. User signs in with Google, Email, Apple, or Passkey when available.
2. User completes basic identity:
   - username,
   - display name,
   - avatar,
   - optional AI/3D avatar placeholder if feasible.
3. User lands directly on Dashboard.
4. Dashboard shows the primary CTA: “Verify your lifestyle”.
5. User selects one or more sport lifestyle interests:
   - Running,
   - Gym / Strength,
   - Cycling,
   - Swimming,
   - Hybrid Athlete,
   - Marathon / Events,
   - Recovery,
   - Wellness,
   - Sports Gear,
   - Supplements.
6. System suggests relevant badges, personal challenges, proof types, and lifestyle opportunities.
7. User submits or simulates proof.
8. User receives a sport lifestyle badge.
9. User can create a personal challenge with deadline/countdown.
10. User builds rank through repeated proof, completed challenges, and referrals.
11. Relevant brands/opportunities appear as matched opportunities, not generic vouchers.

## Scope
This OpenSpec change defines implementation-ready requirements for:
- onboarding and dashboard routing,
- the sport lifestyle passport,
- tiered sport badges,
- lifestyle proof submission/simulation,
- personal challenges,
- sport lifestyle leaderboard/ranking,
- matched lifestyle opportunities.

## Non-goals
- Do not implement application code in this change.
- Do not introduce generic voucher marketplace behavior.
- Do not add unrelated crypto-first or Web3-heavy public language.
- Do not rebuild the entire application foundation.
- Do not remove existing admin/demo functionality unless a future implementation task explicitly requires it.
- Do not define production payment, sponsorship payout, or employment marketplace mechanics in this phase.

## Success Criteria
- The next implementation phase has clear specs for a sport lifestyle pilot.
- User-facing flows are Web2-first and consumer-friendly.
- Badges support Bronze, Silver, Gold, Diamond, and Elite tiers.
- Opportunities are framed as relevant lifestyle matches rather than generic discounts or vouchers.
- Product language consistently reinforces verified lifestyle reputation, ranking, opportunities, and future income/career potential.
